# Réponses non sensibles

Aucun résultat Work n'a encore été enregistré à l'initialisation du relais. Ce fichier conserve le dossier dans Git ; il ne constitue pas une réponse documentaire.

Une réponse réelle utilise le modèle [REPONSE_PUBLIQUE.md](../templates/REPONSE_PUBLIQUE.md) après contrôle du contenu et de la preuve. Les retours remplis du modèle privé restent hors GitHub. Mettre à jour l'index avec la même demande, sans créer de faux résultat ni relancer une demande déjà clôturée.
