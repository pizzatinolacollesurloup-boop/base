# Pizza Tino — Instructions et relais documentaire

Ce dépôt conserve les instructions durables de Codex et les demandes/réponses documentaires **non sensibles**. Google Drive reste la destination des originaux et des documents confidentiels. Le relais avec Work est manuel tant qu'une automatisation autorisée n'a pas été démontrée.

La visibilité publique du dépôt a été vérifiée le 20 octobre 2026. Aucun contenu n'est réputé privé parce qu'il figure dans ce dépôt.

## Reprendre le travail

1. Lire [AGENTS.md](AGENTS.md), puis [l'état des demandes](handoff/INDEX.md).
2. Reprendre la prochaine action de la demande active, sans relancer ce qui a déjà été confirmé.
3. Lire le [protocole Work–Drive–Codex](docs/RELAIS_WORK_DRIVE.md) uniquement si le circuit ou la preuve nécessaire doit être précisé.

## Première demande

[DOC-001](handoff/requests/DOC-001.md) prépare la conservation du lot privé de sources transmis dans la conversation et la récupération de messages manquants. Les pièces à joindre à Work et les précisions confidentielles sont remises séparément dans la conversation ; elles ne sont pas dans ce dépôt.

Le titulaire transmet la demande à une session Work disposant réellement de Drive, accompagnée du paquet privé. Il rapporte le résultat privé dans la conversation Codex. Codex contrôle les éléments reçus et inscrit ici uniquement un compte rendu non sensible. La présence de ces fichiers ne prouve aucun accès à Drive, envoi à Work ou transfert réussi.

Un brief privé lisible directement peut suffire pour commencer : Work recherche d'abord les originaux déjà présents dans Drive. Le titulaire ne doit joindre de nouveau que les pièces réellement manquantes. Aucun aperçu ZIP n'est requis pour cette première recherche, et le brief ne remplace pas les originaux.

## Répartition des emplacements

| Emplacement | Contenu |
|---|---|
| GitHub | Instructions générales, demandes neutres, modèles, états et comptes rendus non sensibles |
| Google Drive autorisé | Originaux, documents métier et dossiers privés ; accès et écritures à vérifier dans la session qui les utilise |
| Conversation ou transmission privée autorisée | Pièces nécessaires à Work, réponses détaillées, références privées et extraits utiles à Codex |

Ne pas placer ici de CV, contrats, bulletins, coordonnées de personnes, montants individuels, documents bancaires, secrets, liens Drive privés ou extraits de conversations confidentiels. Les fichiers locaux ignorés par Git ne sont pas pour autant sauvegardés dans Drive.
